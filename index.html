Shorts Uploader Privacy Policy

Last updated: October 2, 2026 · Contact: dpdp901010@gmail.com

Shorts Uploader is a private desktop tool used by one creator to schedule uploads and read statistics for the creator's own YouTube channels. It is not offered to the public.

Data the tool accesses

  • Basic information about the signed-in YouTube channel (channel ID and title), to confirm the right channel is connected.
  • The channel's own video list, publish schedule and public statistics (views, likes, comment counts).
  • Video files and metadata that the creator chooses to upload from their own computer.

How the data is used and stored

Data is used only to upload the creator's videos and to show the creator their own schedule and statistics. Access tokens and logs are stored only on the creator's own computer. No data is sold, shared with third parties, or used for advertising.

Google API Services

The tool uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service and the Google Privacy Policy. Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time from Google Account → Security → Third-party access. Deleting the tool's tokens folder on the computer removes all stored credentials.
